## 🎯 Sobre este repositorio

Este espacio reúne los trabajos prácticos integradores de la cursada de **Aplicaciones Web 1**. Cada TP se organiza por estudiante para mantener las entregas y sus recursos separados.

## 🗂️ Estructura

```text
TPS-AW1/
├── tp1/
│   └── Octavio Benavidez/
└── tp2/
    └── Octavio Benavidez/
        ├── index.html
        ├── pages/
        └── recursos/
```

Para sumar otra entrega, creá una carpeta con el nombre del estudiante dentro del TP correspondiente. Por ejemplo: `tp2/Alan/`.

> Las carpetas `node_modules` se ignoran en cualquier nivel del repositorio. Ejecutá `npm install` dentro del proyecto que necesites usar.
